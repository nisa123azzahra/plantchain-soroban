# 🌿 PlantChain — On-Chain Plant Diary

## Project Description
PlantChain is a decentralized application (dApp) built on the Stellar blockchain using Soroban smart contracts. It allows users to record, track, and manage their plants entirely on-chain — from seedling to harvest. Every plant entry is stored immutably on the blockchain, ensuring transparent and tamper-proof garden records.

## Project Vision
To empower plant enthusiasts and agricultural communities to digitally document their plant journey on a decentralized network — making plant data ownership trustless, transparent, and permanent on the blockchain.

## Features
- 🌱 **Add Plant** — Record a new plant with name, species, and care notes on-chain
- 📖 **View All Plants** — Retrieve all plant records stored in the smart contract
- ✏️ **Update Plant** — Update growth status (Seedling → Growing → Blooming → Harvested) and care notes
- 🗑️ **Remove Plant** — Delete a plant record from the blockchain by ID
- 📋 **Transaction Log** — Track every on-chain interaction in real time
